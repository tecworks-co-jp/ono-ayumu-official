## 4-4. 案4：飾らない個人サイト

案2を土台に「AIが作ったサイトっぽい」という指摘を受けて組み直した案です。**「テンプレート的なランディングページの記号」を全部外し、本人が自分で書いたように読める** ことを最優先にしています。

**「AIっぽい」と受け取られた要素（案2）と、案4での対応**

| 案2で「AIっぽい」と見える要素 | 案4での対応 |
|------|------|
| 英字のアイブロウ（WHAT I CAN DO FOR YOU / VOICES / FLOW …） | すべて削除。見出しは日本語のみ |
| 絵文字アイコン付きカード（🎤🤝🎙️✍️🧭🌱☕）が7枚並ぶ依頼メニュー | カードをやめ、「ご依頼について」の定義リスト（文章）に |
| 4つの大きな数字（1,000人＋／3,500人＋／3冊／2022〜） | 数字バーを削除。数字は文章の中で1回ずつ触れるだけ |
| ヒーローのタグピル＋マーカー付きキャッチコピー＋ボタン2つ＋写真に浮かぶバッジ | キャッチコピーをやめ、「小野歩のウェブサイトです。」から始まる一人称のあいさつ文＋普通の写真1枚 |
| サンプル文の「ご依頼いただいた方の声」（3枚の引用カード） | 削除（本物が揃ってから載せる） |
| 「ご依頼の流れ」3ステップ、FAQアコーディオン、末尾のCTA帯、スマホ固定CTA | 削除。費用・進め方・よくある質問は「費用と進め方」の段落に文章でまとめた |
| 講演テーマ 01〜07 のカード（対象／時間／形式のdl） | 「講演・研修」の1段落に「よくお話しするのは〜あたりです」と並べるだけ |
| 白カード＋角丸18px＋影＋ホバーで浮く／スクロールでフェードイン／背景のグラデーション | すべて廃止。装飾は罫線だけ。アニメーションなし |
| Google Fonts（Zen Kaku Gothic New / Inter）、深緑×朱橙の2色 | Webフォントなし（ヒラギノ／游ゴシック等のシステムフォント）。色は墨＋リンク色のみ |
| 「〜をお届けします」「〜にお役立てします」「話す・書く・組む」のような整った営業文 | 一人称の口語に書き直し。文の長さと語尾をわざと揃えない。「〜だけです」「〜も。」のような言い切りを混ぜる |
| すべてのカードから「この内容で相談する →」（依頼種別の自動選択） | 導線は冒頭の一文とフッター前のフォームだけ |

**構成**

| セクション | 内容 |
|-----------|------|
| ごあいさつ | 一人称の自己紹介4段落＋写真（ソファのポートレート） |
| お知らせ | 年付きの一覧（刊行、受賞、設立） |
| プロフィール | 登壇写真＋文章＋経歴表（年月・出来事） |
| 著書 | 3冊。書影＋出版社・年＋一言 |
| 講演・出演・掲載 | プレーンなリンクリスト＋イベント企画運営の実績 |
| ご依頼について | 講演・研修／取材・対談・出演／執筆・監修／協業／キャリア・独立の相談＋「費用と進め方」 |
| お問い合わせ | 名前・会社・メール・ご用件だけの簡素なフォーム（送信はダミー） |

| 項目 | 内容 |
|------|------|
| ベースカラー | 紺 `#0a1666`（ヘッダー帯・フッター・新刊バナー） |
| アクセント | 青 `#2f5fc4`（お問い合わせの丸ボタン・リンク） |
| 地色 | 白。お問い合わせ帯のみ薄グレー `#f2f2f2`（ノート罫線風） |
| 見出し書体 | 明朝（Noto Serif JP → 游明朝／ヒラギノ明朝にフォールバック）。字間を広めに |
| 本文書体 | ゴシック（ヒラギノ角ゴ／游ゴシック／メイリオ等のシステムフォント） |
| 演出 | 全画面ヒーロー写真＋下端の紺帯（サイト名＋ナビ）、スクロール誘導の丸矢印、PAGE TOPボタン、カード画像のホバー拡大程度 |

| MESSAGE | センター寄せ・短い行で改行した一人称のメッセージ（案4の「ごあいさつ」「プロフィール」の文章を再構成） |

| 事業内容 | 写真帯の見出し＋3カラム×2段の6分野（出版／講演・研修／コミュニティ／キャリア支援／システム開発・教育／イベント・店舗） |

## 6. プレビュー方法

ビルド不要の静的サイトです。リポジトリ直下の `index.html`（案一覧）をブラウザで開けば、各案に移動できます。

```bash
# 簡易サーバーで（リポジトリ直下で実行）
python3 -m http.server 8000
# → http://localhost:8000        案一覧
# → http://localhost:8000/site1/ 案1
```

案を直接開く場合は `open site1/index.html` でも確認できます。
