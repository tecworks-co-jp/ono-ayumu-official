# 小野歩 オフィシャルサイト（案）

代表 小野歩氏の **著者・個人ブランディング** を目的としたオフィシャルサイトのプロトタイプ（提案版）です。
デザイン案を **複数並べて比較できる** 構成にしています。各案はそれぞれ独立した1枚完結（シングルページ）のHTMLです。

最終更新: 2026-08-28 ／ ステータス: **提案・たたき台**

## 3. サイト構成（案1・1ページ内のセクション）

すべて `site1/index.html` の1ファイルに統合した **シングルページ構成** です。ヘッダーメニューは各セクションへのページ内アンカーになっています。

| アンカー | セクション | 役割 |
|----------|------------|------|
| `#home` | ホーム（Hero）＋実績数字 | 第一印象。キャッチ・肩書き・実績（著書3冊／相談1,000人／月3,000人／創業2022） |
| `#profile` | プロフィール | 経歴ストーリー・タイムライン・価値観・ミッション/ビジョン |
| `#books` | 著書 | 3冊の詳細 |
| `#media` | メディア・活動 | 活動領域・tecHub・メディア掲載一覧・SNS発信 |
| `#contact` | お問い合わせ | 依頼内容の明示＋フォーム（提案用ダミー） |

## 4-2. 案2：依頼・協業を生むサイト

案1が「著者としての信頼性・権威性を伝える」構成なのに対し、案2は **依頼・問い合わせにつなげること** を最優先に設計しています。

**盛り込んだ意図**

| 意図 | 対応するセクション |
|------|--------------------|
| 講演会の依頼がくる | 依頼メニュー／講演テーマ例6本（対象・時間・形式を明記）／ご依頼の流れ／FAQ（謝礼・オンライン・リードタイム）／依頼種別つきフォーム |
| 協業依頼がくる | 「一緒に組みたい方へ」（共催・コンテンツ連携・人材育成・開発）／協業専用のCTA |
| 直接会いたい・一緒に仕事がしたいと思われる | 一問一答で人柄を出す／「30分のオンライン相談から」「tecHubに来れば会える」導線／依頼者の声／「まずは話してみたい」カード |

**デザイン（案1との違い）**

| 項目 | 案1 | 案2 |
|------|-----|-----|
| 配色 | 紺 `#0c2340` × 金茶 `#b8893b` | 深緑 `#123b32` × 朱橙 `#d4552d` |
| 見出し書体 | Noto Serif JP（明朝） | Zen Kaku Gothic New（ゴシック） |
| 印象 | 編集的・落ち着き・読み物 | 行動喚起・温度感・相談しやすさ |
| 導線 | ページ下部のフォームに集約 | 各セクションからフォームへ（依頼種別を自動選択）＋スマホは固定CTAバー |

## 4-3. 案3：ダーク・メディア型

案1が「読ませる」、案2が「依頼させる」構成なのに対し、案3は **出演・掲載・発信の量そのものを見せる** ハブ型です。動画出演や受賞といった実績が増えていくほど強くなる構成で、更新前提のサイトに向いています。

**構成**

| セクション | 役割 |
|-----------|------|
| Hero | 英字リード＋グラデーション見出し。受賞・tecHub・MENTA をメタ情報として1行で提示 |
| 実績マーキー | 掲載・出演・出版社名を横に流す（インプレス／講談社／日経BP／NewsPicks／GLOBIS／TECH PLAY／SCSK／代官山 蔦屋書店 ほか） |
| Now | いまやっていること3つ（経営／コミュニティ／執筆・発信） |
| Media | **出演・掲載カード6枚**（このサイトの主役） |
| Books | 著書3冊。受賞バッジ付き |
| Talk & Work | 依頼できること4つ＋講演テーマのタグ |
| About | 「不断挑戦」＋経歴タイムライン＋基本情報 |
| Follow | note／X／LinkedIn／MENTA |
| Contact | フォーム（提案用ダミー） |

**3案の違い**

| | 案1 | 案2 | 案3 |
|---|---|---|---|
| 目的 | 信頼性・権威性を伝える | 依頼・協業につなげる | 実績と発信を見せる／回遊させる |
| 配色 | 紺 × 金茶（明るい） | 深緑 × 朱橙（明るい） | ダーク × スカイ／バイオレット |
| 書体 | Noto Serif JP（明朝） | Zen Kaku Gothic New | Inter ＋ Noto Sans JP |
| 印象 | 編集的・落ち着き | 温度感・相談しやすさ | 先進的・モダン・テック |
| 向いている運用 | 内容を固めて長く置く | 依頼を取りにいく | こまめに更新して育てる |

## 6. プレビュー方法

ビルド不要の静的サイトです。リポジトリ直下の `index.html`（案一覧）をブラウザで開けば、各案に移動できます。

```bash
# 簡易サーバーで（リポジトリ直下で実行）
python3 -m http.server 8000
# → http://localhost:8000        案一覧
# → http://localhost:8000/site1/ 案1
```

案を直接開く場合は `open site1/index.html` でも確認できます。

## 7. 本番化の選択肢（参考）

| 方法 | 向き | 補足 |
|------|------|------|
| このHTMLをそのまま公開 | 早く・安く出したい | Netlify / Vercel / GitHub Pages に配置するだけ |
| 静的サイトジェネレータ化 | 更新を継続したい | Astro等。お知らせ追加を効率化 |
| ノーコード（STUDIO等）で再現 | 本人/非エンジニアが更新 | このデザインを設計図として再構築 |
| WordPress | ブログ運用重視 | note併用なら必須ではない |
